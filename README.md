# NSB Score Keeper

Built files for https://baodongxliu.github.io/nsb-score-keeper/, a practice score keeper for
National Science Bowl scrimmages. This repository is generated by a deploy script; edit the
source, not these files.

The app itself contains no student data and no quiz questions. `club/pack.json` holds the club's
roster and question bank encrypted (AES-256-GCM, PBKDF2-SHA256 key) with a passphrase known only
to the club's coaches; the app unlocks it on a coach's device, where the data stays.
